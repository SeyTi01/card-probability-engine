# Local Git identity

Inspect the resolved author and committer before creating or rewriting commits. Use the owner's established public GitHub name and verified noreply email; configure only this repository, preserve existing hooks, and never bypass them. Do not infer a public identity from a machine profile.

Review outgoing raw identities, trailers, annotated taggers, messages and changed content before publication. Do not rewrite already-published commits merely to sanitize or tidy history; report the actual conflict.
