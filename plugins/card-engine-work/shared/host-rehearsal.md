# Rehearse a package in its host

Identify the actual consumer, baseline, candidate source commit and package hashes. Use a disposable host checkout and its own instructions/toolchain. Replace the engine dependency with the exact candidate; exclude embedded/linked engine sources and verify exactly one implementation.

Compare public results, policy keys, terminal states and representative performance on equivalent inputs. Exercise affected deployment-runtime behavior in that runtime; label unavailable evidence precisely. Record host revision, configuration, package identity, commands and results at a durable project URL.
