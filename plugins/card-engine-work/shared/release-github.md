# Finish the GitHub Release

Verify the tag's commit, [published consumption](package-feed.md) and [candidate identity](published-identity.md), including matching symbols. Prepare [release notes](release-notes.md) from the actual release range.

Create or complete the matching GitHub Release using those notes and links to candidate/rehearsal evidence. Preserve a correctly published existing release rather than rewriting it to match a newer template. Mark preview versions as prereleases; mark a stable release latest only when no newer stable release already owns that position.

Verify saved notes, tag, prerelease/latest metadata and package link. Return the release and package URLs plus material limits.
