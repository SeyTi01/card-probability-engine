# Calculator rehearsal

Read the calculator's current YGO Work instructions and package-boundary documentation. For the initial extraction, use the embedded baseline recorded in `repo:docs/provenance.md`; later rehearsals use the relevant adopted host revision.

Preserve adapter-derived `PolicyOrderKey`, saved inputs and host-owned worker/progressive contracts. Compare native correctness and representative performance. Verify the production AOT/stripped-IL worker, Fast/Exact, Progressive completion, cancellation and stale-result rejection against the same artifact.

A native or Node-hosted result does not prove browser AOT behavior or causation of a historical runtime defect. Do not permanently upgrade the host dependency as part of a disposable rehearsal.
