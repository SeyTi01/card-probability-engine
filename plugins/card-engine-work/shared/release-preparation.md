# Prepare without publishing

Read `repo:docs/contributing.md` and inspect existing preparation for the requested version. Reuse matching work.

| Requested preparation result | Procedure |
| --- | --- |
| Source/version PR | [Prepare source](release-source.md) |
| Local verified package | [Build candidate](package-build.md) |
| Hosted release candidate from source already on main | [Candidate workflow](release-candidate.md) |

Stop with the requested result. Do not merge, tag, publish to NuGet or create a GitHub Release. Report any unmet dependency on those stages.
