# Mathematical changes

Read `repo:docs/calculation-model.md`, `repo:docs/probability-engine.md` and `repo:docs/accuracy-and-performance.md`. Treat their semantics as contracts; resolve disagreements with source and independent evidence before editing expectations.

Trace physical-copy assignment, hand-wide maxima, overlapping unions, exact weights, hidden losses, phase/activation order and deterministic keep/removal policy through the affected path. Pool or memoize only states equivalent under all future observations; preserve multiplicity and failed-branch mass.

Preserve each mode's result/proof contract and each row's primary versus certified fraction. A speedup, equal rounded percentage or passing implementation-derived expectation does not establish semantic equivalence. Model changes need an explicit compatibility decision through [API compatibility](api.md).
