# Maintain this plugin

Keep each concrete skill usable directly. Put universal rules in shared files; callers must link every mandatory shared rule. A conditional procedure belongs in its own file behind a concrete trigger, never in a leaf the reader must partially disregard. Apply this to limited deliverables and failure recovery as well as technical subjects.

Use one owner per rule. Reference repository contracts instead of copying them. Keep task routing acyclic apart from explicit return-to-caller handoffs. Reuse loaded modules and valid evidence.

| Task | Procedure |
| --- | --- |
| Evaluate or change instructions | [Validate instruction routes](plugin-validation.md) |
| Change packaging code | [Test packaging](plugin-tooling.md) |
| Produce an archive or publish the plugin | [Build archive](plugin-archive.md) |
| Publish an account update | [Update saved plugin](plugin-publication.md) |
