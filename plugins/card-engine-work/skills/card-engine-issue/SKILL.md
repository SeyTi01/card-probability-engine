# Write an issue

Read [context](../../shared/context.md) and [GitHub writing](../../shared/github-writing.md). Inspect current source, relevant discussion and existing issues/PRs to avoid duplicates or stale premises.

Record the concrete problem, observed/intended behavior, useful reproduction/evidence and decided acceptance criteria. Keep unresolved requirements explicit, follow useful repository template fields, and link dependencies.

A draft request ends with draft text. A create/update request uses GitHub tools, verifies the saved issue and returns its link. Issue work needs no SDK, Git credentials or build.
