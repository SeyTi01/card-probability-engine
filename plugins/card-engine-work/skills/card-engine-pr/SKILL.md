# Deliver a PR

Read [context](../../shared/context.md) and [GitHub writing](../../shared/github-writing.md). Identify the task branch and any existing PR; continue that PR instead of duplicating it.

| Requested operation | Procedure |
| --- | --- |
| Title/body only | Inspect the current diff, update the requested metadata, verify and stop. |
| Publish source | [Source delivery](../../shared/pr-source.md) |

Return the verified PR link and material limitations. Ordinary delivery leaves the PR open.
