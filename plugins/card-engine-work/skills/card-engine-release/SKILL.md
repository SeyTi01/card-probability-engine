# Release the engine

Read [context](../../shared/context.md). Establish the deliverable and intended version or release range from the request and remote state. Resolve any version decision required by the selected workflow before writing.

A complete release request authorizes its necessary merges, candidate validation, tag, NuGet publication and GitHub Release; continue without separate routine permission questions.

| Requested deliverable | Procedure |
| --- | --- |
| Notes only | [Release notes](../../shared/release-notes.md) |
| Preparation only | [Release preparation](../../shared/release-preparation.md) |
| Complete release | [Release publication](../../shared/release-publication.md) |

Keep package version, runtime model version and plugin version separate. Resume completed stages from verified remote evidence; do not repeat irreversible writes merely because a previous response was interrupted.
