# Plan the change

Read [context](../../shared/context.md). Establish intended behavior, settled constraints and acceptance criteria.

| Requested work | Procedure |
| --- | --- |
| Format an already supplied plan | Preserve its decisions and produce the requested format. |
| Develop or assess a technical plan | Inspect current source and [affected contracts](../../shared/change-routes.md); resolve ownership and verification from evidence. |

Keep one proportionate plan: baseline, decisions/rationale, affected owners, ordered dependencies and concrete checks. Distinguish proposals from existing behavior. Ask only for blocking decisions.

Standalone planning ends with the plan. Planning invoked by implementation returns to its caller; keep notes internal unless a saved artifact was requested.
